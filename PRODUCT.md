# Retra Product Overview

## Mission
Retra transforms Game Boy Advance emulation from a bare utility into a private, beautifully crafted handheld memory archive.

## Core Pillars
1. **Local-First Privacy**: ROMs, battery saves, save states, screenshots, and settings stay completely local on the device.
2. **Deterministic Integrity**: Checksum-verified imports (.gba, .zip) and accurate patch application (UPS, IPS, BPS) on user-provided base files.
3. **Liquid Glass UI/UX**: Zero generic AI cards or neon SaaS gradients. An original, thoughtful design featuring the Retra Sprite, floating navigation dock, and tactile touch controls.
4. **Authentic Emulation**: Native mGBA libretro core delivering 60 FPS gameplay, responsive controls, customizable layouts, and 1-tap screen rotation.

## Feature Overview
- **Home**: Resumes last-played game instantly with rich artwork and save-state status.
- **Library**: High-performance grid and detailed list views with live filtering and search.
- **Add Flow**: Seamless import for single files, folders, patch files, and built-in legal homebrew demo (*Retra Drift*).
- **Profile**: Private local profile with optional Google account linking for identity personalization.
- **Settings**: Deep customization across themes, display scaling, audio, controller profiles, save timelines, and system diagnostics.
