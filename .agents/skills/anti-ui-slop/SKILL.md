# Anti-UI Slop Design Principles

## Core Tenets
1. **Zero Card Soup**: Do not default to wrapping every data point inside identical rounded rectangles. Create visual hierarchy through scale, editorial typography, whitespace, and intentional composition.
2. **Intentional Materials**: Use translucency and liquid glass purposefully—for floating navigation, overlays, modal sheets, and player controls—not behind raw blocks of body text.
3. **Restrained Color Palettes**: Base surfaces must possess rich tonal depth (deep plum-charcoal, near-black aubergine, graphite) rather than harsh plain black or generic purple SaaS gradients. Use accent colors sparingly to direct attention.
4. **Honest Functionality**: Every control, chip, and statistic must connect to real state and real user capabilities. No fake cloud metrics, fake follower counters, or decorative mock buttons.
5. **Human Micro-Interactions**: Employ organic spring physics, tactile haptic response, and thoughtful state transitions that respect user accessibility preferences (Reduce Motion, Reduce Transparency).
