# Mobile Onboarding Design Principles

## Core Tenets
1. **Emotional Proposition First**: Do not begin onboarding with utility or feature lists. Lead with the core feeling and memories the product unlocks.
2. **Kinetic Typography & Depth**: Use custom display typography, varied Z-depth, subtle parallax, and intentional optical rhythm rather than plain body copy.
3. **Living Mascot Interaction**: Mascots must have authored physical behavior—eye tracking, squash/stretch spring dynamics, inertia, and deterministic reactive states.
4. **Interactive Demonstration**: Show functionality through direct touch exploration (color morphing, layout shifting, filter previews) rather than static screenshot cards.
5. **Calm Culmination & Offline Continuation**: The authentication step should feel like a serene landing. Authentication must never block offline local use.
